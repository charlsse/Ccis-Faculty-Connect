> INTERNAL DRAFT REGISTER - factual implementation observations plus unresolved governance fields. Version 0.1; audited 9 October 2026. No production records or secret values were copied.

## Scope and evidence method

Reviewed database schema metadata from the configured application database, migrations, model casts, forms, controllers, middleware, storage configuration, notifications and integrations. No personal record values were queried for this inventory. The inspected local instance uses MySQL, database sessions, SMTP and a local filesystem. Those observations are not verification of a production deployment.

All processing owners, legal bases, approved retention periods, processor agreements and transfer assessments below remain **REQUIRES REVIEW**. Proposed role ownership is not an institutional appointment. Financial or employment context does not justify inventing a legal basis. Proofs, photos and free text require assessment for incidental sensitive information.

## Observed schema scope

The current schema contains 24 application tables: account_management_locks, announcements, audit_logs, cache, cache_locks, failed_jobs, jobs, job_batches, migrations, notifications, password_reset_tokens, payments, sessions, site_contents, trusted_devices, users, water_collections, water_members, water_notices, water_payment_accounts, water_receipts, water_reference_claims, water_settings and water_submissions. The optional gateway migration is in `database/experimental/paymongo`, outside the normal migration directory. Unrelated databases on the same server were excluded.

## Local configuration observations - not deployment assurance

Database sessions are configured with HTTP-only cookies, SameSite=Lax, a 120-minute idle lifetime, payload encryption disabled and Secure-cookie disabled in this local environment. SMTP is configured, but provider identity, TLS operation and email delivery were not verified. Do not carry these observations forward as a production security claim. A production launch review must verify HTTPS/Secure cookies, session protection, keys, storage permissions, backups, mail and operator access.
